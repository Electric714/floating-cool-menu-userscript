# 🌀 Floating Cool Menu + Pro Storage Editor

**Custom draggable floating menu userscript for Safari on iOS (and all browsers) with full storage editor (cookies, localStorage, sessionStorage).**

## ✅ What's Fixed in v2.8
- **Initial floating icon now properly shows and loads** — no more invisible or broken icon!
- Fully draggable rocket icon (mouse + touch support with redundancy)
- Tap/click the icon to open the cool menu
- Menu intelligently positions near the icon
- **Pro Storage Editor**: View, edit, add, delete items live for:
  - Cookies
  - localStorage
  - sessionStorage
- Position persists across page reloads
- Safe-area-insets for notched iOS devices
- GM.addStyle fallback for broader compatibility
- Optimized for **Userscripts app (quoid)** on iOS Safari

## Installation
1. Install a userscript manager:
   - **iOS Safari**: [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) by quoid
   - Desktop: Tampermonkey, Violentmonkey, etc.
2. Open the raw script: [floating-menu.user.js](https://raw.githubusercontent.com/Electric714/floating-cool-menu-userscript/main/floating-menu.user.js)
3. Click **Install** in your manager.

## Features
- Beautiful glowing rocket icon (🌀) that you can drag anywhere
- Cool dark glassmorphism menu
- One-tap access to powerful storage tools
- No permissions beyond what's needed
- Lightweight & fast

## How to Use
1. After install, a glowing rocket icon appears bottom-right on every page.
2. **Drag** it to your preferred spot (position saves automatically).
3. **Tap** it to open the menu.
4. Choose **Pro Storage Editor** to manage all your storage data instantly.
