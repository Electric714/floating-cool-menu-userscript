# Floating Cool Menu Userscript

Custom draggable floating menu userscript for Safari on iOS with full storage editor (cookies, localStorage, sessionStorage).

## Complete iOS Safari Compatibility

This script is optimized for use with the open-source **Userscripts** app (https://github.com/quoid/userscripts) on iOS/iPadOS Safari.

**Redundancy features added:**
- Fallback CSS injection (GM.addStyle or manual style element)
- Robust touch and mouse event handling
- Early injection (@run-at document-start)

## Installation Instructions for iOS Safari

1. Install the [Userscripts app](https://apps.apple.com/us/app/userscripts/id1463298887) from the App Store.
2. In Safari, visit the raw script URL:
   https://raw.githubusercontent.com/Electric714/floating-cool-menu-userscript/main/floating-menu.user.js
3. The Userscripts app will detect and offer to install the script.
4. In the app, enable the script and configure it for `*://*/*` or specific sites.
5. The floating 🚀 menu should appear on pages.

## Features
- Draggable floating rocket menu
- Quick actions (dark mode, scroll top, refresh, etc.)
